## 0.1.0

- Android: dark navigation bar (default #0D0D0F) with light buttons on the host Activity window.
- Re-applies on attach, resume (posted), window focus gain, and configuration change.
- Read-only diagnostics snapshot and optional logcat logging.
- Verified in the `example/` harness on one Android 16 device (3-button and gesture navigation, Light and Dark system theme). Not yet verified inside a production app.
